# Research Report: VN30F Derivatives Contract Naming Convention

**Date:** 2026-02-25
**Scope:** HoSE/HNX Vietnamese futures contract naming, VN30F symbol format, SSI FastConnect usage

---

## Executive Summary

VN30F futures contracts follow a well-established naming format: `VN30F` + 2-digit year + 2-digit month (e.g., `VN30F2603` = March 2026). This format has been used since the Vietnam derivatives market launched in 2017 and remains the de-facto standard used by brokers, data platforms, and SSI FastConnect API.

A **new 9-character internal code format** was introduced by HNX effective **May 5, 2025** for back-office/settlement purposes (e.g., `41I1F9000`). However, the legacy `VN30FYYMM` format continues to be used by trading platforms, brokers, and the SSI FastConnect API for market data and order entry.

---

## Key Findings

### 1. Standard Naming Format (Market-Facing)

**Format:** `VN30F` + `YY` + `MM`

| Part | Meaning | Example |
|------|---------|---------|
| `VN30` | Underlying asset: VN30 index | — |
| `F` | Futures contract type | — |
| `YY` | 2-digit expiration year | `26` = 2026 |
| `MM` | 2-digit expiration month | `03` = March |

**Example:** `VN30F2603` = VN30 Index Futures expiring March 2026

This format has been stable since market launch in 2017.

### 2. Four Active Contract Months at Any Time

HNX always maintains exactly 4 active contracts:
1. Current month (front month)
2. Next month
3. End of nearest quarter (Mar/Jun/Sep/Dec)
4. End of next quarter

As of **February 2026**, the 4 active contracts are likely:
| Symbol | Expiry | Type |
|--------|--------|------|
| `VN30F2602` | Feb 2026 | Current month (front) |
| `VN30F2603` | Mar 2026 | Next month |
| `VN30F2606` | Jun 2026 | Nearest quarter-end |
| `VN30F2609` | Sep 2026 | Next quarter-end |

Final trading day: **third Thursday** of the expiry month (or prior trading day if holiday).

### 3. New HNX Internal Code Format (from May 5, 2025)

HNX introduced a new 9-character transaction code structure for internal/settlement use:

**Format:** `VN` + `[9-char transaction code]` + `[1-char dedup]`
Full code = 12 characters, e.g., `VNVN30F25063`

The 9-char transaction code breaks down as:
| Position | Meaning | Value |
|----------|---------|-------|
| 1 | Security type | `4` = Derivatives |
| 2 | Security group | `1` = Futures |
| 3-4 | Underlying asset | `I1` = VN30 index |
| 5 | Expiration year | letter (A=2017, ..., F=2025(?)) |
| 6 | Expiration month | digit `1`-`9`, `A`-`C` |
| 7-9 | Identifier | `000` = futures |

Example: `41I1F9000` (VN30 futures Sep 2025)
The final 1-char dedup code (`0`–`Z`) is auto-generated by the system.

**Important:** This new format is for HNX's internal system. **Brokers and data APIs (including SSI FastConnect) continue using `VN30FYYMM` format** for market-facing symbol identification.

### 4. SSI FastConnect Symbol Format

SSI FastConnect uses two symbol representations for derivatives:

**a) Generic/Rolling codes** (for continuous data):
- `VN30F1M` — front month (nearest expiry)
- `VN30F2M` — second month
- `VN30F1Q` — nearest quarter-end
- `VN30F2Q` — next quarter-end

**b) Specific contract codes** (exact expiry):
- `VN30F2602`, `VN30F2603`, `VN30F2606`, `VN30F2609`
- Same `VN30FYYMM` format as HNX market standard

The SSI FastConnect Data API accepts both formats. Real-time streaming channels use the specific codes (e.g., `X:VN30F2603`) while some REST endpoints support the generic codes.

### 5. No Naming Change for Market-Facing Symbols

The `VN30FYYMM` format has NOT changed for:
- Trading platforms (SSI, MAS, VNDIRECT, VPS, etc.)
- SSI FastConnect API
- Market data feeds (Vietstock, CafeF, etc.)
- Broker order entry systems

The May 2025 change only affected HNX's **internal** settlement code structure. All public-facing market data, APIs, and trading interfaces retain the `VN30FYYMM` convention.

## Comparative: Old vs New HNX Codes

| Aspect | Old (pre-May 2025) | New (post-May 2025) |
|--------|-------------------|---------------------|
| Market symbol | `VN30F2509` | `VN30F2509` (unchanged) |
| HNX internal code | `VN30F2509` | `VNVN30F25063` |
| Length | 9 chars | 12 chars |
| Auto-dedup | No | Yes (0–Z suffix) |
| Used in trading | Yes | No (internal only) |

# Generic front-month alias (some endpoints)

# Deriving active contracts programmatically:
